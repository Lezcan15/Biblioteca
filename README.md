# 📚 Biblioteca

Proyecto de gestión de una biblioteca desarrollado en **Java** con **Maven**.

El objetivo del proyecto es practicar y consolidar conceptos fundamentales de programación orientada a objetos en Java mediante una aplicación sencilla de gestión de libros y usuarios.

## 🛠️ Tecnologías

* Java 21
* Maven
* Git / GitHub

## 📖 Funcionalidades

Actualmente el proyecto se encuentra en desarrollo.

La aplicación está orientada a permitir la gestión básica de:

* Libros
* Usuarios
* Préstamos y devoluciones
* Disponibilidad de libros

## 🎯 Objetivos del proyecto

Este proyecto forma parte de mi proceso de aprendizaje y práctica de **Java**, con especial atención a:

* Programación Orientada a Objetos (POO)
* Clases y objetos
* Encapsulación
* Herencia y polimorfismo
* Interfaces
* Colecciones
* Manejo de excepciones
* Buenas prácticas de programación
